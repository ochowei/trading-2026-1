# Workflow Authoring Compatibility Pointer

This legacy path remains only for callers that have not yet adopted progressive disclosure. It is
not a second authority and does not contain the complete authoring contract.

Read the mode-specific canonical references instead:

- [`core.md`](core.md): shared identity, repository, authority, and validation invariants.
- [`create.md`](create.md): initial family creation, document import, and source disposition.
- [`evolve.md`](evolve.md): active-version changes and replacement drafts.
- [`remove.md`](remove.md): abandon, retire, and removal classification.
- [`release.md`](release.md): approved release preparation and immutable evidence.
- [`impact.md`](impact.md): active-version, dependency, and unfinished-study impact.

Study operation and evaluation use
[`../../../rules/workflow-study-governance.md`](../../../rules/workflow-study-governance.md), not
this compatibility pointer.
