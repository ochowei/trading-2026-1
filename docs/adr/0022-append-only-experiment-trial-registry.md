# Retain every formal experiment trial

Each new formal research-definition fingerprint is permanently registered as an experiment trial within a declared asset and experiment family, together with its hypothesis, snapshots, timestamps, and outcome status. Re-evaluating the same definition on later data adds an observation rather than a trial, ephemeral runs do not qualify for decisions, and failed or deleted implementations remain in the append-only registry. This makes selection pressure visible and prevents parameter changes or renaming from erasing the multiple-testing history.
