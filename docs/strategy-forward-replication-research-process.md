# 策略前瞻驗證流程（簡版）

## 目的

這套流程只想回答一個問題：**一個在歷史資料上看起來不錯的策略，是否值得繼續用未來資料驗證，最後投入使用？**

它主要防止幾件事：反覆嘗試直到碰巧成功、看過答案後改策略、低估交易成本，以及把少數好年份誤認為長期有效。

這是一份研究規劃，不是程式規格，也不代表策略已獲准自動下單。

## 三段資料各做一件事

| 階段 | 用途 | 可以改策略嗎？ |
| --- | --- | --- |
| 研究期（Development） | 研究、比較並選出唯一候選策略 | 可以 |
| 歷史驗證期（Evaluation） | 用後續歷史資料檢查候選策略 | 不可以 |
| 未來模擬期（Shadow） | 從當下開始，像真實交易一樣累積新證據，但不下真單 | 不可以 |

在**同一輪研究**中，每個交易日期只能屬於其中一段，三段期間不能重疊。例如 2018 年不能
同時是研究期和歷史驗證期。

只要某段資料或結果曾經影響策略設計，它就不能再作為該策略的驗證證據。資料角色在同一輪
研究中不能改變；舊資料只有在開啟下一輪研究後，才可以改列為研究資料，但下一輪必須另留
更晚、尚未看過的驗證資料。

為了計算驗證期一開始的指標，可以讀取前一段期間的資料作為前置資料，但那些日期仍屬於
原本的期間，不能計入驗證績效。跨越兩段期間的持倉如何處理，也必須事先決定。

## 開始前先定好規則

在正式研究前，先寫清楚：

- 策略為什麼可能有效，以及什麼結果代表假說不成立；
- 三段資料互不重疊的起訖時間；
- 指標前置資料與跨期持倉如何處理；
- 最多允許嘗試多少個版本；
- 如何從研究期選出唯一候選；
- 預估的手續費、滑價與其他交易成本；
- 最大可接受回撤；
- 什麼叫通過、失敗或證據不足；
- 哪些改動會被視為一個新策略。

這些規則要在看到驗證結果前決定，不能事後放寬。

## 流程

### 1. 在研究期選出候選

研究期可以調整訊號、參數和進出場方式，但所有選擇與改良只能根據研究期的資料和研究
結果，不能查看或參考歷史驗證期與未來模擬期的資料或結果，也要遵守預先設定的嘗試上限。

結束時只留下：

- 一個候選策略；
- 一個較簡單的比較基準；
- 曾影響選擇的重要嘗試紀錄；
- 固定的策略、成本、風險與判定規則。

如果達到嘗試上限仍沒有合格候選，就停止這次研究。

### 2. 用歷史驗證期檢查固定策略

驗證期間不能調參、換資料或改成功門檻。它只能回答候選策略是否通過，不能用來重新挑選冠軍。

除了逐年結果，也要查看不中途重設資金的完整資本變化，避免漏掉跨年持倉、長期回撤或資金長時間無法回到高點的問題。

一旦查看歷史驗證結果，這段驗證資料就已經被這一輪研究使用。若候選失敗，這一輪研究立即
結束，不能修改策略後再用同一段資料驗證。即使修改時只重新查看研究期資料，因為已經知道
上一次失敗，原本的驗證期也不能再次充當未見資料。

失敗後可以選擇停止，也可以開啟下一輪研究。下一輪可以把舊的驗證資料納入研究，用來了解
失敗原因與設計新策略，但必須另留一段更晚、尚未看過的資料重新驗證。最後找不到具體原因
或改良方法，也是合理的研究結論。

例如第一輪使用 2018–2020 年研究、2021–2025 年驗證，策略 A 在驗證期失敗後：

- 不能修改成 A2，再用 2021–2025 年重新證明 A2；
- 可以在下一輪把 2018–2025 年當成研究資料，但新策略必須使用更晚的未見資料驗證。

### 3. 主動挑戰策略

候選策略至少要和下列對象比較：

- 持有現金；
- 較簡單的同類策略；
- 承擔相近市場風險的隨機進場。

也要檢查小幅改參數、延後一天交易、提高成本、成交較差、漏單，以及不同市場環境時，結果是否很快崩壞。

這些測試和判定方式也必須事先決定，只能用來判斷原候選是否穩健。若測試產生新想法，要
另開一輪研究並使用新的驗證資料，不能直接替換原候選。

### 4. 進行未來模擬

歷史驗證通過後，從當下開始模擬真實執行，完整記錄每天的訊號、模擬成交、成本與結果，但不送出真實訂單。

如果等待時間已到但交易筆數不足，就繼續等待。期間只要修改策略，這一輪便結束；先前的
未來模擬資料可以納入下一輪研究，但不能算作新策略的未來模擬證據。新策略凍結後，等待
時間與交易筆數都要重新累積。

### 5. 受控啟用並持續觀察

未來模擬通過，只代表可以考慮啟用。真正投入使用前，仍要確認策略版本、最新資料、部位、資金與風險限制都正確。

啟用後若表現明顯惡化、資料不完整、樣本不足或風險檢查失敗，就停止新進場。恢復前必須累積新的合格證據，不能只靠人工改狀態或降低門檻。

既有部位仍應依原定出場規則管理。

## 建議的最低門檻

| 項目 | 最低要求 |
| --- | ---: |
| 研究期 | 3 個完整連續年度，另加指標所需的前置資料 |
| 歷史驗證期 | 5 個完整連續年度 |
| 歷史驗證完成交易 | 至少 20 筆 |
| 有交易的驗證年度 | 至少 3 年 |
| 正報酬的交易年度 | 至少 60% |
| 一般與較高成本下的報酬 | 都必須為正 |
| 較高成本下的回撤 | 不得超過預先設定的上限 |
| 結果集中度 | 單一年份不得占超過 50% 的交易或獲利 |
| 未來模擬 | 至少 252 個交易日及 12 筆完成交易 |

這些只是最低資格，不是獲利保證。策略越複雜、交易越少、曾嘗試的版本越多，就需要更多未來證據。

## 結果只有四種

- **通過**：所有必要條件都符合，才進入下一階段。
- **證據不足**：維持原策略並繼續等待，不降低門檻。
- **失敗**：停止這個候選；若有新想法，建立新版本並重新開始。
- **無法判定**：資料或紀錄不完整，停止晉級與新進場，直到問題補齊。

只要策略規則有實質改變，就視為新策略，不能沿用舊策略的驗證資格。舊的驗證資料若被用來
研究或改良，也不能再驗證新策略。

## 要留下的紀錄

每次研究至少保留：研究假說、資料期間、嘗試過的版本、選擇理由、成本與風險假設、各階段結果，以及所有通過、拒絕、暫停和恢復決定。

通過這套流程，只代表目前的證據值得繼續信任，不代表未來一定獲利。程式、指令與資料格式等技術內容由其他文件維護，不放在這份規劃裡。
